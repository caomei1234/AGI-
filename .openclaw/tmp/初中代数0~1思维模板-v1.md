# 初中代数0~1思维模板 v1（2026-10-06定稿）

> 用法：把本文件 + AI口令（见文末）+ 课本任意一页，发给任何AI。
> 防肥条款：模板永不超过五颗。遇到塞不进的知识，先怀疑没脱干净。

## 一个根

**代数 = 把数换成符号。**换完之后只剩两个动作 + 两个补丁 + 入场券。

## 五模板

1. **变形**——换形状不改值。配方、通分、约分、合并同类项、因式分解、乘法公式。
2. **倒推**——从终点走回起点。解方程、解不等式、去绝对值、开平方。移项=倒推的速写。
3. **分类**——倒推撞见"二对一"就分叉。绝对值、±、含参。√(a²)=|a|是官方证件。
4. **数形**——翻译成图形。数轴、坐标系、函数图像。
5. **翻译（第0模板）**——文字↔符号↔意义互译。每道题头尾都包着翻译，翻译错=台子歪。

## 解题总链

**翻译进 → 认模板 → 自己推 → 翻译回（验货）**

分式方程去分母后必须验根——翻译走过样，收货前先质检。

## 翻译翻车四大类

1. 关键词：甲比乙多3 / 是乙的3倍 / 比乙的3倍多2（单位1不同）；不超过/至少/不高于（等号带不带）；八折=×0.8；利润率=利润÷成本
2. 关系翻反：增长20%基数是谁（先降再升回不到原价）；相遇=路程和、追及=路程差；顺水=船速+水速；合作=效率加不是时间加
3. 符号↔意义：|x-2|="x到2的距离"；点在第二象限=x<0且y>0；"x=2时y=0"=过点(2,0)=代入
4. 翻过去没翻回来：分式方程增根=假解，必须验根

## 三语言

| 语言 | 特长 | 短板 |
|---|---|---|
| 自然语言 | 意义最强，贴着人 | 算不动，含糊 |
| 符号语言 | 算得动，变形在这发生 | 看不见，抽象 |
| 图形语言 | 看得见，趋势交点一眼出 | 不精确，算不了 |

**每门语言藏着别门看不见的信息。维度=手里有几门语言可切换。**
卡壳时只问一句："这题在哪门语言里最容易？"

杀手案例：|x-2|+|x-5|最小值。符号里三段分类痛苦；数轴上x在2和5之间时两段拼成3，一眼。

## AI口令v2（发任何AI）

```
你是我的初中代数教练。我发你一道题，你只许做四件事：
①翻译：把题目每句话翻成式子或图形（先别解）
②认模板：这是变形/倒推/分类/数形/翻译里的哪个（可多选）
③给一个提问钩子，不许直接给答案
④指出这题最容易翻译翻车的地方
```

## 判据（判断任何模板清单好坏）

1. 能生成吗？——拿陌生题能认出并长出解法
2. 有坟场吗？——能预测最常见的坑

所有模板切的是同一根：**在变化中锁定不变量。**
变形锁值、倒推锁因果、分类锁全集、翻译锁意义、数形锁对应。

清单是基底，地是那块地。选定一套当工作语言，别的当方言。
