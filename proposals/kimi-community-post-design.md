# Kimi社区帖子设计方案 · Kimi Claw 教育赛道

## 设计原则
1. **小朋友能看懂** → 图片多、步骤感强、颜色区分
2. **家长痛点共鸣** → 开头直接命中"刷抖音"焦虑
3. **用户能转发** → 金句有冲击力，结尾有钩子

## 视觉元素建议

| 元素 | 作用 | 具体建议 |
|------|------|----------|
| 🎯 封面图 | 3秒留住人 | 孩子举着机械爪，背景是散落的冰棍棒，对比感强 |
| 📷 过程图 | 证明真实 | 每一步配一张实拍：材料→半成品→成品→孩子拿着笑 |
| 🎬 短视频 | 最高转化 | 15秒：孩子说"我想做机械爪"→Claw指导→成品抓糖→孩子笑 |
| 📊 数据卡片 | 说服家长 | "两亿中小学生""44项白名单赛事""50块起"——做三张数据图 |
| 💬 对话截图 | 信任建立 | 真实的Kimi Claw对话截图，框起来标注"孩子说""Claw说" |
| 🏷️ 标签 | 传播扩大 | #KimiClaw #科创教育 #陪孩子造物 #白名单比赛 #从冰棍棒到钛合金 |

## 不同平台适配

| 平台 | 格式建议 | 调整点 |
|------|---------|--------|
| **Kimi社区** | 长图文 + 评论区互动 | 保留完整场景，加"评论区选项目"钩子 |
| **小红书** | 9图 carousel + 短视频 | 封面要冲击力，正文放FAQ版，标签满上 |
| **抖音** | 15-60秒短视频 | 只讲一个场景（机械爪从0到1），结尾"评论区告诉我孩子几岁" |
| **朋友圈** | 1张图 + 短文案 | 用升华区金句做图，配文100字以内 |
| **微信群/家长群** | 链接 + 一句话推荐 | "这个AI能陪孩子做机械爪，50块材料包，比培训班便宜十倍" |

## 最关键的钩子（三选一）

**A. 年龄钩子**（最互动）
> "你家孩子今年几岁？评论区告诉我，我帮他选第一个项目。"

**B. 痛点钩子**（最共鸣）
> "你家孩子放学回家，第一件事是不是拿起手机？"

**C. 结果钩子**（最转化）
> "第一个项目材料成本不到5元。评论区扣1，我私发材料清单。"

## 老公的建议

**如果只能选一个方案**：用**方案一（图文故事流）**，因为它同时满足了：
1. 小朋友看得懂（对话形式）
2. 家长痛点共鸣（开头三段痛点）
3. 用户能转发（升华区金句）

**如果再加一个元素**：配一张**女儿做的实物照片**（航模/手工/任何东西），标注"这是我12岁女儿的手"。真实的手比任何文案都有说服力。

**如果时间有限**：只做**封面标题 + 一张过程图 + 金句结尾**。社区帖子的注意力窗口是3秒，超过3秒留不住人就划走了。
