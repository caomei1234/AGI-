## 文章格式规范（执行层）

**种子版一律用分行诗格式，不用 `>` 引用块。**

另外：当收到对话中直接粘贴的种子版内容时——**自动在行间加空行**。不需要问。不需要提醒。直接执行。

正确格式：
```markdown
**种子版**

第一行诗

第二行诗

第三行诗

---
```

错误格式（不要再用）：
```markdown
> **种子版**
>
> 第一行诗
> 第二行诗
```

原因：引用块在 GitHub 手机上渲染成灰色大框，阅读节奏被压缩。分行诗每行之间空一行，诗的节奏清晰可见。
