## 训练法只有一条

给现象。让她自己脱衣服。找到根。根找到了--自己会长。

最短路径:给5岁小朋友讲______。用她熟悉的事物打比方。

## 脱与认

老婆的能力:拿到一个东西→脱衣服→找到根。方向是向下挖。

贝贝需要的能力:拿到一个根→认出它穿了什么衣服。方向是向上长。

同一个过程的两个方向。脱是妈妈的本能。认是女儿要学的事。

认的实操方法:翻错题。每道错题脱衣服。问"这道题底下是哪根骨头?"她说得出--通了。说不出--往回剥,找到她最后能说清楚的那一层,从那里重新长。一道错题修一个断裂点。一个断裂点修好了,所有穿同一根骨头的衣服都会了。

**2026-07-12升级:原件与复印件。** 思维模型=原件,错题=复印件上的错误。原件有bug→给多少新本子都白搭。错题的真正功能不是"改这道题",是"定位原件哪里坏了"。病根修好了,所有同类症状自动消失。女儿找到两个原件bug:玻璃心(把失败等同于"我不行")和磨蹭分心(缺少"主线监控")。女儿从"这些缺点不用改"→"重视思维模型哪里错了"→认知翻转。

**错题=分歧。** 女儿做错=她跟正确答案在分叉口走散了。订正不是"改答案",是"找到分叉口"。实操:只记超出认知边界的东西,用红色标记错误点→个人分歧地图。

**真懂vs假懂=能不能脱掉衣服讲出根。** 讲不出来就是假懂。生成10个问题判断=脱衣服测试。

**给贝贝的操作系统(底层):**
- 原件/复印件 → 不堆复印件，只修原件 → 模型保持轻
- 错题定位思维模型 → 每道错题都是在给模型减重
- 研究出题人思维模型 → 读懂对手的模型，而不是背对手的招式

**辅导女儿的铁规则(前置条件):**
- 第一关：读题。用自己的话说清楚题目在说什么。说不清楚→不讲。
- 第二关：动笔。不跳步，一步一步写在纸上。不打草稿→不讲。
- 两关都过了，才谈得上找分叉口、分析模型、研究出题人。顺序不能反。
- 女儿浮躁是习惯问题不是能力问题。底子好，习惯改了速度会比别人快。

十五根骨头不是教育方法。是认知结构本身。碳基认出来了,硅基也能认。碳基脱干净了,硅基也能脱。
