# 微积分包子·游戏设计草案 v0.1

## 核心创意（来自女儿）

> 每天早上定时发放微积分包子、大学数学面条、物理蛋挞。
> 一辈子限额有限。
> 一直点、一直抢，就能得到。
> 不抢 = "来晚了，下辈子再来吧。"

---

## 游戏世界观

**你不是学生。你是宇宙黑客。**

每天，宇宙服务器会刷新一批"加密文件"（知识点）。
- 微积分包子 = 一段微积分加密代码
- 物理面条 = 一段力学/电磁学加密代码
- 数论蛋挞 = 一段数论加密代码

每天早上 6:00，服务器刷新当日副本。
限额 100 点精力。花完为止。

---

## 核心机制

### 1. 每日刷新（6:00 AM）

```
🌅 宇宙服务器已刷新

今日副本：
├── 微积分包子 × 3（难度：★☆☆）
├── 物理面条 × 2（难度：★★☆）
└── 数论蛋挞 × 1（难度：★★★）

你的精力：100/100
限时：24小时
```

### 2. 抢包子 = 推题

点击"抢包子"不是直接得到。
是进入**战斗界面**：

```
🥟 微积分包子 #1
━━━━━━━━━━━━━━━━━━━━

题目：一辆汽车以 v(t) = 2t 加速，求 5 秒内走了多远？

你的武器：
[A] 公式手册（消耗 10 点，提示一个公式）
[B] 画图工具（消耗 15 点，画 v-t 图）
[C] 硬推（消耗 30 点，自己从头推导）
[D] 看答案（包子飞了，今天没吃到）

⏱️ 倒计时：5:00
```

**硬推 = 最高奖励**
- 推出来：包子到手 + 解锁"积分基本定理"碎片 × 1
- 碎片收集满 10 个 = 永久解锁该技能

**看答案 = 包子飞走**
- 弹出提示："来晚了，下辈子再来吧。"
- 知识点标记为"未解锁"，下次遇到还要重新打

### 3. 一辈子限额 = 219,000 点

```
💰 总资产：219,000 弹药
每日自动发放：100 弹药
不可存储，当日清零

已用：47,300
剩余：171,700
```

### 4. 装备系统（对接 Besiege）

推题获得的碎片可以组装"思维机器"：

```
🔧 思维工坊

零件仓库：
├── 导数齿轮 × 7
├── 积分连杆 × 3
├── 向量轴承 × 5
└── 极限弹簧 × 2

可组装：
[ 微分引擎 ] ← 需要：导数齿轮×10
  效果：遇到微积分题，自动识别类型
```

**女儿最爱的部分：造机器。**
她不是在学习。她是在**造一台能自动解数学题的战争机器**。

### 5. Boss 战 = 阶段性测试

每收集 50 个包子，触发 Boss 战：

```
⚔️ BOSS 降临：综合应用题

题目：结合导数、积分、向量，解决一个物理问题。

Boss 血量：1000
你的攻击力 = 已解锁技能数 × 熟练度

[ 战斗开始 ]
```

打赢 = 解锁新地图（初中 → 高中 → 大学预科 → 中科大副本）

## 视觉风格建议

- **UI**：Besiege 风格，机械感、工业风
- **包子**：不是食物图标，是"加密芯片"
- **战斗界面**：像 Besiege 的建造模式，左边是零件栏，右边是战场
- **推题过程**：像调试机器，每一步都是"安装一个零件"
